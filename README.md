# ErgoBot

ErgoBot is a posture-monitoring robot that uses computer vision to track a user's sitting posture and mirror their movements through a physical, servo-driven model. By combining personalized calibration, ergonomic scoring, and real-time visual and physical feedback, ErgoBot aims to help users recognize and correct poor posture during prolonged desk work.

## Features
- Real-time posture tracking using MediaPipe and OpenCV
- Personalized posture calibration
- Ergonomic scoring informed by RULA and REBA
- Flask-based web dashboard with posture analysis
- Servo-driven robotic feedback

## Technologies
Python, Flask, MediaPipe, OpenCV, HTML, CSS, JavaScript, MicroPython, RP2040

## Purpose
ErgoBot combines computer vision, robotics, and ergonomics to make posture feedback more noticeable and accessible. It is intended for ergonomic awareness, not medical diagnosis.
